# yoga-studio

Сайт-визитка для йога-студии «Гармония» в Казани.

## Что использовал
- HTML: семантическая верстка (`header`, `main`, `section`, `table`, `form`, `address`)
- CSS: Flexbox для построения сетки (шапка, карточки, форма)
- CSS: эффекты при наведении (`:hover`), тени (`box-shadow`, `text-shadow`), скругления (`border-radius`)
- CSS: позиционирование `sticky` для закрепленной шапки

## Особенности проекта
- Главный экран с призывом к действию
- Таблица с расписанием занятий
- Карточки инструкторов с круглыми фото
- Блок с абонементами (выделен популярный тариф)
- Форма обратной связи с выпадающим списком и валидацией
